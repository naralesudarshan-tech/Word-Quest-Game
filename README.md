# Word-Quest-Game
Game Overview – Word Quest

Word Quest is an engaging, console-based word-guessing game developed in Python. Inspired by the classic Hangman logic, it challenges players to uncover a hidden word one letter at a time. With simple controls and fun visual feedback, it offers a nostalgic yet entertaining experience for all ages.

 Core Gameplay
 Objective

Guess the hidden word correctly before your attempts run out.

 Progressive Discovery

Each correct guess reveals the matching letters in the word, gradually helping you solve the puzzle.

 Limited Attempts

Players are allowed a maximum of 6 wrong guesses.
If all chances are used, the game ends.

 Visual Feedback

A dynamic ASCII-art hangman visually represents your current progress. With each wrong guess, a part of the hangman appears — bringing tension and excitement to the game.
